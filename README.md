Shadow Courier is an original top-down stealth game: sneak through a guarded warehouse at night, steal every document and reach the green EXIT unseen. Guards patrol with vision cones cut by walls and crates, a detection meter fills when they spot you, and you can crouch in shadow, click-to-move or use WASD. Three levels, three lives, score and ghost bonuses, and synthesized WebAudio sound with no external files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
